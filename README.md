# «Русское слово» — лендинг репетитора

Одностраничный сайт репетитора по русскому языку: подготовка к ЕГЭ и ОГЭ, мастерская сочинений, русский как иностранный.

**Сайт:** [russkoeslovo.online](https://russkoeslovo.online/)

Чистый HTML, CSS и немного JavaScript — без сборки, фреймворков и зависимостей. Чтобы посмотреть локально, достаточно открыть `index.html` в браузере.

## Состав

```
index.html      — главная страница (все разделы на одной странице, переходы по якорям)
oferta.html     — договор-оферта
politika.html   — политика обработки персональных данных
css/site.css    — все стили
js/site.js      — меню, появление блоков, FAQ, окна документов, запись через мессенджеры
js/theme.js     — переключатель цветовых палитр (сейчас скрыт)
img/            — фотографии (WebP), иконки, превью для соцсетей, QR-код WeChat
fonts/          — шрифты Unbounded (заголовки) и Manrope (текст), кириллица и латиница
favicon.ico     — иконка сайта для поисковиков и старых браузеров
robots.txt, sitemap.xml — для поисковиков
```

Шрифты лежат на самом сайте, внешних подключений нет.

## Как устроено

- **Запись на занятие** без сервера: посетитель выбирает цель, сайт собирает текст сообщения и открывает Telegram, MAX, ВКонтакте или показывает QR-код WeChat. Сайт ничего не хранит и никуда не отправляет.
- **Цвета** заданы CSS-переменными (`--p` основной, `--a` акцент, `--hl` выделения, `--bg` фон, `--sf` подложки, `--tx` текст). Основная палитра — в начале `css/site.css`. Переключатель других палитр в `js/theme.js` выключен (`SHOW_SWITCHER = false`).
- **Адаптивность:** вёрстка проверена на ширинах 320–1920 px в Chrome и Safari.
